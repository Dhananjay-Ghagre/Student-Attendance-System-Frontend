# Frontend - Student Attendance System

Modern React frontend with responsive design and interactive dashboards.

## Features

### 🎨 Modern UI/UX
- **Tailwind CSS** for responsive, mobile-first design
- **Lucide React** icons for consistent visual elements
- **Toast notifications** for user feedback
- **Interactive charts** using Recharts
- **Clean, professional layout** with role-based navigation

### 📱 Responsive Design
- Mobile-optimized layouts
- Adaptive grid systems
- Touch-friendly interfaces
- Cross-device compatibility

### 🔐 Authentication
- JWT-based secure login/registration
- Role-based access control
- Persistent sessions
- Demo credentials provided

### 📊 Role-Based Dashboards

#### Admin Dashboard
- User management with role filtering
- Course creation and assignment
- System-wide statistics
- Interactive charts (Pie, Bar)
- Responsive data tables

#### Teacher Dashboard
- Course management interface
- Quick attendance marking
- Visual attendance reports
- Daily/monthly trend analysis
- Student performance tracking

#### Student Dashboard
- Personal attendance overview
- Course-wise performance metrics
- Monthly attendance trends
- Interactive progress indicators
- Detailed attendance history

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm start
```

Frontend runs on http://localhost:3000

## Technology Stack
- **React 18** with Hooks
- **React Router** for navigation
- **Tailwind CSS** for styling
- **Recharts** for data visualization
- **React Hot Toast** for notifications
- **Lucide React** for icons
- **Axios** for API communication
